3) AUTO-TOP-UP TRIGGER
When credits are spent, check if balance dips below threshold, then queue auto-top-up.

Implement in the credits debit path:
- Wherever you “burn credits,” after successful debit transaction:
  - compute new creditsBalance
  - if autopay enabled and creditsBalance < threshold:
    - enforce cooldown + caps:
      - cooldownMinutes since lastTopupAt
      - count succeeded topups in last 24h / 7d from wallet_ledger
    - if allowed: create autopay_attempt row queued and kick off charge

Charge method:
- Create Stripe PaymentIntent:
  - customer: stripeCustomerId
  - amount: pack.priceCents
  - currency: 'usd'
  - off_session: true
  - confirm: true
  - payment_method: default customer PM (retrieve from Stripe)
  - description: "Credits Hub Auto Top-Up: {packSku}"
- Use Stripe idempotency key:
  "autotopup:{userId}:{YYYYMMDD}:{packSku}:{n}" (or based on attempt id)
On success:
- ledger autopay_topup_succeeded
- ledger credits_granted
- update lastTopupAt
On failure:
- ledger autopay_topup_failed (no credits)
- save failure code/message in autopay_attempt
- optionally disable autopay if repeated failures (e.g., 3 failures)

IMPORTANT: Auto-top-up should be best-effort and never block the primary user action. If it fails, user continues but sees banner: “Auto-top-up failed—add funds.”
