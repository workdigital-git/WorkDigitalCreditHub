# MusicForge - Credits Hub OAuth Integration

## Overview

MusicForge uses Credits Hub OAuth2 for user authentication. This document describes the complete authentication flow, endpoints, and expected responses.

## Required Environment Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `CREDITS_HUB_URL` | Base URL of Credits Hub | `https://workdigitalcredithub.com` |
| `CREDITS_HUB_CLIENT_ID` | OAuth Client ID | `client_dc4156179c7aa8aeb377dd4b9acce7fc` |
| `CREDITS_HUB_CLIENT_SECRET` | OAuth Client Secret | (secret value) |
| `SESSION_SECRET` | Session encryption key | (secret value) |

## Authentication Endpoints

### 1. Login Initiation
**Endpoint:** `GET /api/auth/login`

**Description:** Initiates the OAuth flow by redirecting the user to Credits Hub.

**Redirect URL Generated:**
```
{CREDITS_HUB_URL}/api/oauth/authorize
  ?client_id={CREDITS_HUB_CLIENT_ID}
  &redirect_uri={protocol}://{host}/api/auth/callback
  &response_type=code
  &scope=openid profile credits
  &state={random_64_char_hex}
```

**Example Full Redirect URL:**
```
https://workdigitalcredithub.com/api/oauth/authorize
  ?client_id=client_dc4156179c7aa8aeb377dd4b9acce7fc
  &redirect_uri=https://workdigitalmusic.com/api/auth/callback
  &response_type=code
  &scope=openid%20profile%20credits
  &state=abc123...
```

---

### 2. OAuth Callback
**Endpoint:** `GET /api/auth/callback`

**Description:** Receives the authorization code from Credits Hub after user grants permission.

**Expected Query Parameters from Credits Hub:**
| Parameter | Description |
|-----------|-------------|
| `code` | Authorization code to exchange for tokens |
| `state` | Must match the state sent in login request (CSRF protection) |
| `error` | (Optional) Error code if authorization failed |

**Example Callback URL:**
```
https://workdigitalmusic.com/api/auth/callback
  ?code=AUTH_CODE_HERE
  &state=abc123...
```

---

### 3. Token Exchange
**Request to Credits Hub:**
```
POST {CREDITS_HUB_URL}/api/oauth/token
Content-Type: application/json

{
  "grant_type": "authorization_code",
  "code": "{authorization_code}",
  "redirect_uri": "https://workdigitalmusic.com/api/auth/callback",
  "client_id": "client_dc4156179c7aa8aeb377dd4b9acce7fc",
  "client_secret": "{CREDITS_HUB_CLIENT_SECRET}"
}
```

**Expected Response from Credits Hub:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "openid profile credits",
  "user": {
    "id": "uuid-string",
    "email": "user@example.com",
    "fullName": "John Doe"
  }
}
```

---

### 4. Userinfo Request
**Request to Credits Hub:**
```
GET {CREDITS_HUB_URL}/api/oauth/userinfo
Authorization: Bearer {access_token}
X-App-ID: client_dc4156179c7aa8aeb377dd4b9acce7fc
```

**Expected Response from Credits Hub:**
```json
{
  "id": "uuid-string",
  "email": "user@example.com",
  "fullName": "John Doe"
}
```

---

### 5. Check Current User
**Endpoint:** `GET /api/auth/user`

**Description:** Returns the currently authenticated user.

**Response (authenticated):**
```json
{
  "user": {
    "id": "internal-uuid",
    "externalId": "credits-hub-uuid",
    "email": "user@example.com",
    "fullName": "John Doe"
  }
}
```

**Response (not authenticated):**
```json
{
  "user": null
}
```

---

### 6. Logout
**Endpoint:** `GET /api/auth/logout`

**Description:** Destroys the session and redirects to home page.

**Redirect:** `/`

---

## Credits Hub OAuth Client Configuration

The following must be configured in Credits Hub for this client:

| Setting | Value |
|---------|-------|
| Client ID | `client_dc4156179c7aa8aeb377dd4b9acce7fc` |
| Allowed Redirect URI | `https://workdigitalmusic.com/api/auth/callback` |
| Scopes | `openid`, `profile`, `credits` |

## Authentication Flow Diagram

```
User clicks "Sign In"
        │
        ▼
GET /api/auth/login
        │
        ▼
Redirect to Credits Hub ──────────────────────────────┐
https://workdigitalcredithub.com/api/oauth/authorize  │
  ?client_id=client_dc4156179c7aa8aeb377dd4b9acce7fc  │
  &redirect_uri=https://workdigitalmusic.com/api/auth/callback
  &response_type=code                                  │
  &scope=openid profile credits                        │
  &state={random}                                      │
        │                                              │
        ▼                                              │
User authenticates on Credits Hub                      │
        │                                              │
        ▼                                              │
Credits Hub redirects back ◄───────────────────────────┘
https://workdigitalmusic.com/api/auth/callback
  ?code={auth_code}
  &state={same_random}
        │
        ▼
GET /api/auth/callback
        │
        ├── Validate state matches session
        │
        ▼
POST {CREDITS_HUB_URL}/api/oauth/token
  (exchange code for access_token)
        │
        ▼
GET {CREDITS_HUB_URL}/api/oauth/userinfo
  (fetch user profile)
        │
        ▼
Create/update user in database
Store userId and access_token in session
        │
        ▼
Redirect to / (home page)
```

---

## Session Storage

- Sessions are stored in-memory using `memorystore`
- Session cookie settings:
  - `secure: true` in production
  - `httpOnly: true`
  - `sameSite: "lax"`
  - `maxAge: 24 hours`

---

## Error Handling

If any step fails, the user is redirected to `/?error={error_code}`:

| Error Code | Description |
|------------|-------------|
| `auth_failed` | Credits Hub returned an error |
| `no_code` | No authorization code in callback |
| `invalid_state` | State mismatch (possible CSRF attack) |
| `token_failed` | Token exchange request failed |
| `no_token` | No access_token in token response |
| `userinfo_failed` | Failed to fetch user info |
| `no_user` | No user data in userinfo response |
| `auth_error` | General authentication error |

## B2B API Calls (Credits Billing)

For charging credits, use the access token with X-App-ID header:

```javascript
fetch('https://workdigitalcredithub.com/api/b2b/balance', {
  headers: {
    'Authorization': 'Bearer ' + access_token,
    'X-App-ID': 'client_dc4156179c7aa8aeb377dd4b9acce7fc'
  }
})
```
